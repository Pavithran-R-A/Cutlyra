## Native (non-npm) mobile dependencies — M10 on-device captions

Neither of the two items below is committed to this repo; on Android the
whisper.cpp sources are cloned at build time by
`apps/mobile/scripts/fetch-whisper-cpp.sh` and compiled by CMake into
`libcutlyra_whisper.so`, and the model weights are downloaded at build
time into the APK assets — both are gitignored build inputs, so "what
ships inside the APK" includes them even though no binary of either is
checked in. They are referenced by name and by URL from code in this
repo (`scripts/download-whisper-model.sh`,
`android/app/src/main/cpp/cutlyra_whisper_jni.cpp`), and this document's
own stated purpose is to have one answer to "what licenses does this app
ship with" rather than requiring someone to re-derive it later.

- **`ggml-org/whisper.cpp`** — MIT. Integration: native plugin, iOS
  (Metal/Core ML via `whisper.xcframework` — planned, not yet embedded)
  and Android (JNI, `libcutlyra_whisper.so`, built from the pinned
  `v1.9.2` checkout — see `WhisperJNI.java`'s and
  `cutlyra_whisper_jni.cpp`'s doc comments for exact status).
- **OpenAI Whisper model weights** (`ggml-tiny.en.bin` / `ggml-base.en.bin`,
  fetched from `huggingface.co/ggerganov/whisper.cpp` at build time by
  `scripts/download-whisper-model.sh`, never committed — see that script's
  header comment) — MIT (the `openai/whisper` repo's own declared
  license for the original model weights the GGML conversion is derived
  from).

Both captioning inputs are MIT. Other dependency licenses are enumerated

explicitly above.
