## 3. Responsive caption layout (composition-derived)

`packages/editor-core/src/captions/layout.ts` rewritten. Font size =
`shortSide × clamp(fontSize/432, 0.015, 0.1)`; usable width = 82% when the
composition is portrait (h > w) else 88%; greedy word wrap, max 3 lines,
auto-fit shrink in 5% steps; `Intl.Segmenter`-aware splitting keeps emoji and
Tamil clusters atomic; vertical placement clamped to ±0.45h title-safe bounds.
Nothing reads screen pixels, viewport, or DPI — only composition
`canvasWidth`/`canvasHeight`. Deterministic tests cover 1080×1920, 720×1280,
1080×1080, 1080×1350, 1920×1080, 1280×720.
