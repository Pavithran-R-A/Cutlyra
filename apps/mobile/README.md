# apps/mobile — Cutlyra Capacitor 8 shell

The real Cutlyra mobile app: a Capacitor 8 shell (Android + iOS) loading a
locally-bundled Vite/React bundle — `@cutlyra/mobile-ui`'s `EditorShell`,
wired to `@cutlyra/editor-core` through `@cutlyra/native-bridge`. The app
boots a project list → the real editor (`src/app/app-root.tsx`); a legacy
raw-JSON diagnostics harness is still reachable behind the `#/diagnostics`
route, and the M1 spike screen behind `#/autotest`/`spike.html` (both
throwaway diagnostics, see `docs/SPIKE-GUIDE.md`).

## Layout

- `src/` — the app shell (React entry, home screen, boot/runtime prep) and
  the legacy diagnostics entries.
- `android/` — the Kotlin/Gradle Android project
  (`app.cutlyra.editor`, minSdk 29, targetSdk 36, arm64-v8a):
  `NativeBridgePlugin` (Photo Picker/SAF import, Media3 proxy transcode,
  Media3 Transformer export with a custom cross-fade compositor,
  keyframe-aware export), `edl/EdlParser.kt` (the EDL v1 native parser,
  parse-or-reject), whisper.cpp JNI captions under `src/main/cpp/`, and
  JVM unit tests under `app/src/test/`.
- `ios/` — the Swift shell (kept working; not the v0.1.0 priority).
- `scripts/` — build helpers and the build-time fetches for on-device
  captions (see "Captions build inputs" below).
- `www/` is the Vite build output (gitignored, regenerated by
  `bun run build`); Capacitor syncs it into both native shells.

## Building

```sh
# from apps/mobile/
bun run build            # Vite -> www/
bunx cap sync android    # copies www/ into android/app/src/main/assets/public

# Android — debug APK
cd android && ./gradlew assembleDebug
# -> android/app/build/outputs/apk/debug/app-debug.apk

# Android — JVM unit tests (no emulator needed)
cd android && ./gradlew testDebugUnitTest

# iOS — simulator, unsigned
xcodebuild -project ios/App/App.xcodeproj -scheme App -configuration Debug \
  -sdk iphonesimulator -destination 'generic/platform=iOS Simulator' \
  CODE_SIGNING_ALLOWED=NO build
```

`scripts/build-android-debug.sh` and `scripts/build-android-release.sh`
wrap the same Android sequence (the release script signs only when the
`CUTLYRA_RELEASE_*` keystore env vars are set — see `docs/RELEASING.md`).

## Captions build inputs

On-device captions (whisper.cpp via JNI) need two build-time fetches, both
gitignored and never committed:

```sh
bash scripts/fetch-whisper-cpp.sh            # whisper.cpp v1.9.2 sources (MIT)
bash scripts/download-whisper-model.sh tiny.en --platform android
```

The Android NDK + CMake 3.22.1 must also be installed. Without these, the
app still builds and runs; `libcutlyra_whisper.so` is simply not bundled
and generating captions fails with a clear error naming the missing pieces.

## Toolchain notes worth knowing before touching this

- **Deployment floors are patched onto the Capacitor-generated defaults**,
  not the CLI's out-of-the-box numbers: iOS
  `IPHONEOS_DEPLOYMENT_TARGET` 17.0 in
  `ios/App/App.xcodeproj/project.pbxproj`; Android `minSdkVersion` 29 in
  `android/variables.gradle`. Re-running `bunx cap add ios|android` (e.g.
  after deleting a platform to regenerate it) resets both — reapply.
- **The bridge-import gate is real here.** App files under `src/` never
  import `@capacitor/*` directly — platform info comes from
  `(await getNativeBridge()).platform`. `scripts/invariants.sh`'s
  bridge-import gate and the `no-restricted-imports` ESLint rule enforce
  this.
- **Media custody is container-relative.** Imported media is copied into
  the app's private storage and persisted with storage-RELATIVE paths
  (`NativeBridge.getMediaRoot()` + `media/native-paths.ts`), so saved
  projects survive app updates/reinstalls; see
  `packages/editor-core/src/media/native-paths.ts`.
